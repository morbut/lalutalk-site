OpenVoice AAC is a test version of a picture-communication app for children. It is built to work without the internet and to keep everything on the iPad.

What the app keeps on the iPad

  • The boards: words, pictures, board names, colours and their change history.
  • Photos and voice recordings an adult adds to buttons.
  • Settings: voice, speed, touch settings and the adult lock. The PIN is stored only as a salted hash.
  • Automatic backups (the last 14), in the app's folder in the Files app.
  • The usage log, only if an adult turns it on. It records which button was pressed and when, with no sound and no free text. It can be deleted from the app at any time and is not part of backups.

None of this is sent anywhere by the app. The app has no accounts, advertising, analytics or tracking, and it does not use the internet.

What can leave the iPad, and only when an adult does it

Files you share yourself. "Back up now and share" and "Report a problem" open the iPad's share sheet, and you choose where the file goes. A backup contains the boards, photos and recordings. A problem report contains only what you type, plus counts and settings: app build, iPadOS version, screen size, the number of boards, buttons, photos and recordings, and the values of the settings. A report never contains words, board names, photos, recordings, the usage log or the PIN. The app shows you the full report before you share it.

A backup folder you choose. If an adult chooses one in Backups → "Copies in a folder", the app copies each automatic backup (boards, photos, recordings) into that folder. If the folder is in iCloud Drive, Apple stores it in your own iCloud account under Apple's terms, and we have no access to it. "Stop copying" ends this. Copies already in the folder stay until you delete them in the Files app.

The test versions have no internet features. An optional AI helper exists in the source code but is left out of these builds. If it is ever offered, this policy will describe it first.

TestFlight

Test versions are installed through Apple's TestFlight app. Apple, not this app, collects some information under Apple's privacy policy and shares part of it with us:

  • the email address or name you were invited with, and whether you installed the app;
  • crash reports, and basic usage counts such as the number of sessions, if you allow TestFlight to share them;
  • anything you send with TestFlight's "Send Beta Feedback", including screenshots.

We use this only to run the test and fix problems, and we do not pass it on. Please don't send screenshots that show your child's face, name or photos. You can ask us to delete what we hold about you at the contact address above.

Children

The app is meant to be set up and changed by an adult, and the adult area is behind a lock. A child using the app enters no personal information, and nothing a child does is sent anywhere. Adults should not put a child's full name or other identifying details into a problem report.

Permissions the app asks for

  • Microphone: only when an adult records a word for a button.
  • Camera and photo library: only when an adult adds a photo to a button.
  • Face ID or passcode: only to reset a forgotten adult PIN.

Deleting your data

Deleting the app deletes everything it stored on the iPad. Backup files you shared, and copies in a folder you chose, are under your control. In the app, an adult can delete the usage log. To leave the test, delete the app and, if you like, tell us so we remove your invitation.

Changes

If what the app does changes, this page changes before the new version is offered to testers.
